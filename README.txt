# Сайт плиточника Артура (Ялта и ЮБК)

## Структура папки проекта:
- `index.html` — Главная страница сайта.
- `css/style.css` — Стили, цвета и адаптивный дизайн.
- `js/script.js` — Интерактив отзывов, форма отправки и панель управления.
- `images/` — Папка для ваших фотографий объектов (загружайте сюда примеры работ).

## Инструкция по использованию на Samsung S24 Ultra:
1. Скачайте и распакуйте архив **`artur_site_folder.zip`** в приложении «Мои файлы».
2. Откройте папку и запустите `index.html` через ваш браузер (Chrome или Samsung Internet).
3. Чтобы управлять отзывами (удалять их), нажмите кнопку «Управление» в правом верхнем углу сайта и введите пин-код: `1234`.
